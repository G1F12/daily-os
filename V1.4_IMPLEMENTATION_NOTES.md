# DAILY OS v1.4 — Life & School (simplified, original v1.3 visual style)

## Scope requested by user

Only FOUR additions to the established v1.3 PWA:

1. **One-time Tasks**: independent tasks with optional due date, priorities, notes, CRUD, complete/reopen and persistence. Does NOT affect the existing recurring routines, streaks or Perfect Day metrics.
2. **School**: subjects, homework, tests and projects with dates and status, plus quick access from Today. School entries use the same independent task model, not parallel conflicting records.
3. **Daily Review**: read-only summary derived from existing saved day state, personal/school completions, PLN Money records and measured weights.
4. **Weekly Report**: on-demand Monday–Sunday summary; rest days are neutral and unavailable readings are never invented.

## Explicitly REMOVED from the previous v1.4 draft

- New JJK character Opening, 16 SVG portraits and 2 AI WebP portraits: **removed**.
- Opening Atmosphere effects, custom character CSS, Setting switch, schema flag, image pre-cache: **removed**.
- ALL changes to the original v1.3 Opening component, visual mapping, and service-worker visual handling: **reverted** to exact authoritative `abe764f` files.
- Existing v1.3 JJK **quotes** (683 overall, 164 JJK, 40 Gojo), existing 52 themed SVG and 2.8-second standard Opening **remain exactly as before**. The user did NOT ask to remove legacy quotes or Opening.

## UI behavior

The original v1.3 global styling, header, five-tab bottom navigation, colors, existing task cards, quote, Money, Weight, History and Settings layout remain intact. Only small **additive cards** on existing screens and a School sub-screen reached from Today are added; no new main-navigation tabs or redesign. `src/style.css` preserves all canonical v1.3 rules byte-for-byte, with additional `life-*` scoped classes only.

## Data model

- Keep IndexedDB database `daily-os`, database version **1**, store `state`, key `main`.
- Optional additive `State.life` = `{ actions, subjects }`, initialized on migration/read if missing.
- Life entries validated before import; up to 2000 actions and 80 subjects; no opening state modification.
- Export backup envelope **v5**, import legacy v1–v5 and legacy non-envelope state. Restore still uses atomic IndexedDB write.
- No server, account, analytics telemetry, cloud, notifications or background agent.
