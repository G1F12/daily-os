# Original opening artwork

All 60 files in `public/openings` are original vector compositions created for DAILY OS. No third-party photograph, anime frame, manga panel or official promotional image is included. Abstract symbols are thematic, not reproductions of a character or an existing composition. Artwork can be used and modified with this project. Each quote maps to a compatible theme and one stable variation; missing artwork falls back to the garden theme. All small SVGs are part of the offline shell.
